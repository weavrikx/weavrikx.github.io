开源 · 无需 Root · 完全本地

连上指定 WiFi，自动拦掉分心 App

WiFi 哨兵（WiFi Beacon）把「自律」绑到你最熟悉的场景：一到家、一进自习室连上那个 WiFi，抖音、小红书、游戏就会撞上一面全屏警告墙。断开 WiFi 即自动解除。

下载 APK（最新版） 看源码（MIT）

Android 8.0+ · 约 5 MB · 不收集任何数据

它怎么工作

1. 绑定 WiFi

把你「想专注」的 WiFi（家里、图书馆、自习室）加进白名单。

2. 连接即自律

手机一连上该 WiFi，自律模式自动开启，无需手动切换。

3. 拦掉分心 App

打开你标记过的 App，立刻弹出全屏警告遮罩，一键回到正事。

4. 规则全在本地

基于无障碍服务实现，不用 Root，不联网上传，不上报任何使用数据。

从源码构建

git clone https://github.com/weavrikx/wifiwarn.git
cd wifiwarn
./gradlew assembleDebug        # JDK 17 + Android SDK 34，产出 app/build/outputs/apk/debug/

没有 Android Studio 也能编译：仓库内已含 gradle wrapper；CI 构建方法见下方技术文章。

技术文章

无 Root 获取前台 App
